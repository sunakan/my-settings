- `disable-model-invocation: true`（L5）が設定されており、明示呼び出し限定。

- `when_to_use`（L4）が独立フィールドとして存在し、呼び出し判断の文脈が明確。
- `` !`git diff --staged` ``（L12）で動的コンテキストを取得している（チェック [2] 動的コンテキスト）。
