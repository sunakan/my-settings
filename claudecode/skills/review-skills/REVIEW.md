# REVIEW: review-skills

> レビュー日時: 2026-05-07
> ファイル: claudecode/skills/review-skills/SKILL.md

## 総評
SKILL.md をベストプラクティスに照らしてレビューするスキルで、一括・単体の両モードを持つ高機能なスキル。175行と適切な範囲内で、サブエージェント並列起動のパターンも正しく実装されている。`context: fork` と `disable-model-invocation: true` が設定されており安全性・独立性も高い。全体的に高品質で、軽微な改善余地のみ。

## ✅ 良い点
- `context: fork` が設定されており（分類: A — ファイル書き込みで完結）、メインコンテキストを汚染しない
- `disable-model-invocation: true` が設定されており、自動トリガーを防止している
- `when_to_use` フィールドがあり、呼び出し判断の文脈が明確
- `argument-hint` があり、引数の使い方が明示されている
- 一括レビューモードで全スキルを **1メッセージ内にサブエージェントを並べる** 明示がある（並列起動の最良パターン）
- 各サブエージェントへのプロンプトテンプレートが具体的に記載されている
- Step 3 でサマリを出力する集約ステップが明示されている
- 4つのチェックカテゴリ（Frontmatter・Body・サブエージェント・セキュリティ）が網羅的
- 単体レビューモードでのフォールバック（スキルが見つからない場合の処理）が明記されている
- git 操作禁止の制約が冒頭に明記されている
- `allowed-tools` に `Write Edit Agent` が含まれており、REVIEW.md への書き出しと Agent 起動で確認プロンプトが出ない

## ⚠️ 改善提案（任意対応）
- **一括レビューモードのプロンプトテンプレートで `subagent_type` 未明示**: サブエージェントへのプロンプトに `subagent_type: general-purpose` の明記がないため、実行時に type が曖昧になる可能性がある。テンプレート内に明記することで一貫性が高まる
- **単体モードのパス探索でグローバルパスが `~/` 表記**: `~/.claude/skills/` は環境によってシェル展開されない場合がある。絶対パスかシェル展開を明示する記述を検討
- **`agent: Explore` の指定**: `context: fork` を付けているが `agent` フィールドがない（デフォルトは `general-purpose`）。書き込みを含むため `general-purpose` が正しいが、明示するとより意図が明確になる
